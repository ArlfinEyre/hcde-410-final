# hcde-410-final

A preliminary HCDE 410 data-study proposal exploring how negative Steam reviews of *Sid Meier’s Civilization VI* describe specific problems and propose improvements. The planned study combines descriptive analysis of review metadata with qualitative coding of review content; no results have been collected yet.

**A4 proposal:** [A4_preliminary_proposal.ipynb](A4_preliminary_proposal.ipynb)

**Source:** [Steam User Reviews API](https://partner.steamgames.com/doc/webapi/IUserReviewsService) · [Steam API Terms](https://steamcommunity.com/dev/apiterms). The MIT license covers only original project work, not Steam's data or reviewers' text.
