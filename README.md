# HCDE 410 Final Project — A4 + A5

**Project:** Beyond Thumbs Down: What Negative Steam Reviews Tell Us About Player Feedback.

This repository contains the A4 preliminary proposal extended into the **A5 Final Project Plan**, studying how negative reviews of *Sid Meier's Civilization VI* identify problems and propose improvements.

**[Read the A4 + A5 research notebook](HCDE410_A4_Proposal.ipynb)**

The notebook includes the research questions, background and references, sampling and manual coding methodology, reproducible Steam API collection code, feasibility checks of publicly visible reviews, and an AI use statement.

**Important limitation:** The visible-review pilots are small, nonrandom convenience samples. Official Steam API batch collection and representative-sample analysis have **not** been completed. No population-level estimates are claimed.

**Sources:** [Steam User Reviews API](https://partner.steamgames.com/doc/webapi/IUserReviewsService) · [Steam API Terms](https://steamcommunity.com/dev/apiterms) · [Civilization VI](https://store.steampowered.com/app/289070/).

Raw review text and reviewer identifiers should not be committed to this public repository. The MIT license covers original project code and documentation, not Steam's review data.
